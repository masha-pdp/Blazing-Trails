# Blazing Trails

Blazing Trails — это интерактивное веб-приложение на Blazor WebAssembly, предназначенное для создания, просмотра и редактирования туристических маршрутов.

## 🧭 Основной функционал

- Просмотр списка маршрутов с описанием и изображениями
- Добавление нового маршрута с валидацией формы
- Редактирование и удаление маршрутов
- Поддержка загрузки и отображения изображений
- Маршрутизация с параметрами (подробный просмотр маршрута)
- REST API-интеграция через `HttpClient`

## 🔧 Используемые технологии

- **Blazor WebAssembly (.NET 8)**
- **C#**
- **ASP.NET Core**
- **FluentValidation** (валидация форм)
- **Dependency Injection**
- **HttpClient**
- **Git / GitHub**
